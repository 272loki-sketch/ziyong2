# Version 1.7.0

Release date: September 18, 2026

## Major Features

* 小说开演: 在导演室导入并消化小说后，选择开演节点、填写新角色身份、查看公开开场预览，并创建独立的小说演出会话。原著资料经过证据校验后才进入开场预览。

* 原著分支演出: 原著节点作为候选大纲接入现有 StageEngine。当前 Session Tree 的事实优先，用户改变剧情后不会被原著候选直接覆盖。回档和分支使用各自的祖先链。

> Action required: This version is available on `feat/novel-play-foundation`. Review the remaining limitations below before merging or deploying it.

## Minor Features

* 小说构建任务: 支持分块处理、断点续跑、取消、重试和无事件章节跳过。任务状态、版本包和开场预览均有明确的失效边界。

* 开演向导: 使用阶段和节点序号作为起点选择标签，避免在选择阶段显示未来事件标题。预览令牌一次有效并绑定当前会话和角色卡。

* 故障恢复: 对重复开演、会话变化、请求断开、模型取消、路径越界和切卡超时提供确定性门禁与恢复提示。

## Fixes

* 角色身份隔离: 修复新角色身份沿用旧 persona 的问题。玩家姓名和身份会写入新开演配置，作品演出身份与玩家身份分开。

* 原文路径安全: 构建前检查真实路径和文件归属，拒绝目录穿越及符号链接逃逸。

* 测试稳定性: 将依赖本地未提交角色卡、世界书和用户 Skill 的回归测试改为隔离测试资料。最终验证包含 87 项小说专项、958 项全量回归和前端构建，全部通过。

## Release boundary

- 当前版本只支持新角色进入，不支持接管原著角色。
- 阶段按原文分块形成，不是语义篇章。
- 尚未完成真实模型和浏览器人工长篇游玩验收。
- 共享访问机制不提供新增的多用户账户隔离。
- 功能分支尚未合并到 `main`。

详细流程、API、限额和恢复方式见 [小说开演实施说明](NOVEL-PLAY.md)。
