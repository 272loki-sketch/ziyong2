## 已实现

- `src/novel-play/source.ts` 复用 CorpusEngine 的 `splitChapters`、`chunkText` 和默认分块大小。不新建上传、清洗、任务队列或模型客户端。
- 从 ready 文档的已保存清洗文本创建源索引。校验长度和块数，并用文本 SHA-256 区分同名同大小内容。这个局部指纹不修复现有 CorpusEngine 上传去重方式。
- 原文证据采用块索引和 UTF-16 字符区间，要求引用逐字匹配。证据定位有效不代表模型解读正确，语义审查仍需由提取流程完成。
- 作品包生成版本指纹，校验阶段顺序、稳定节点标识、因果依赖和证据。输入必须是已解析的类型数据，尚未实现不可信模型 JSON 的解析器。
- 导演候选只取当前阶段、当前节点及其后续公开节点，标为 candidate。显式因果前提被当前祖先链上的冲突证据否定后，相关候选被排除。
- 候选预算按完整序列化字符数计算，不冒充精确 Token 计数。超限省略完整候选，不截断事实句。
- 七组 node:test 测试。尚未执行，不能据此宣称通过。

## 边界

这是导演候选筛选，不是 writer 安全投影，不保证段落内部没有剧透。公共节点标记必须由后续提取与审阅流程正确产生。

`ancestorEntryIds` 必须来自真实 Session Tree 祖先链。冲突证据还需在接线时校验条目类型、正文与状态来源，不接受导演提案自证。`conflictsReady` 在当前分支校准未完成时应为 false。

此版本仅有事件与阶段数据，没有人物、关系、知情检查点、开演快照或持久化存储。不能把 digest 摘要直接宣布为已发生事实。
